# Chromium-Compound-Classification-ML

-Classified chromium compounds from high-dimensional X-ray spectra 

-Implemented supervised learning algorithms using gradient descent and loss-function optimisation, alongside K-means clustering for unsupervised learning 

-Used undersampling and vectorised computations to improve computational efficiency when working with large datasets

Contains:

-ML1_code.ipynb python code from jupyter notebook

-Written_reports.pdf written reports

-test_agd.ipynb test notebook for adjusted gradient descent function
